# Jihad Kazi — Portfolio Website

Performance Marketer & AI Automation Strategist portfolio with case studies.

## 🚀 Deploy to Vercel (Step by Step)

### Step 1: GitHub এ upload করো

1. [github.com](https://github.com) এ login করো
2. **New repository** → নাম দাও: `jihad-portfolio`
3. **Public** রাখো, README add করো না
4. Create repository click করো
5. তারপর এই files গুলো upload করো:
   - `index.html`
   - `style.css`
   - `script.js`
   - `vercel.json`
   - তোমার CV PDF file: `Jihad_Kazi_CV_Redesigned.pdf`

### Step 2: Vercel deploy করো

1. [vercel.com](https://vercel.com) এ login করো (GitHub দিয়ে)
2. **New Project** → তোমার `jihad-portfolio` repo select করো
3. Framework: **Other** select করো
4. **Deploy** click করো
5. ২ মিনিটে live হবে!

### Step 3: Custom domain (Optional)

`jihadkazi.vercel.app` — এটাই তোমার free URL হবে।  
Custom domain চাইলে: Settings → Domains → Add your domain
